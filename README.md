# HSLuv - Human-friendly HSL

This website is hosted on [https://www.hsluv.org](https://www.hsluv.org)

The reference implementation is [written in Haxe](https://github.com/hsluv/hsluv-haxe).

The [snapshots](snapshots/) are the conformance test data that every implementation
is tested against. See [snapshots/README.md](snapshots/README.md) for the format and
for how to test a port.

To build website:

```
npm run build
```

To start localhost server:

```
npm run serve
```
